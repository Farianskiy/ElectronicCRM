# Версионирование настроек аналогового распознавания

## Что реализовано

Для области «производитель + тип товара» добавлена отдельная версия настроек предложений по похожим товарам. До появления активной версии используется системная конфигурация, повторяющая прежнее поведение: минимум три подтверждающих товара, минимум три товара с характеристикой, согласие не ниже 80 %, до трёх альтернатив и выборка до 2000 товаров.

Сохранение в рабочем пространстве создаёт черновик. Черновик имеет последовательный номер, имя, канонический JSON настроек, SHA-256 хэш и PostgreSQL-версию строки для защиты от одновременного редактирования. Черновик не влияет на импорт и распознавание.

Конфигурация содержит общие пороги и настройки отдельных характеристик. Для характеристики доступны режимы:

- `Off` — предложение не рассчитывается;
- `Shadow` — результат рассчитывается для наблюдения, но не предлагается пользователю;
- `Suggest` — результат можно предложить пользователю;
- `AutoFill` — зарезервирован для отдельного безопасного этапа автоматического заполнения.

Для каждой характеристики можно переопределить минимальное число подтверждений и минимальную долю согласия. Размер кандидатной выборки ограничен диапазоном 100–10000.

Расчёт сохраняет идентификатор, номер и хэш использованной конфигурации в снимке основания решения. Поэтому изменение активной настройки делает ранее сохранённое основание отличимым от текущего.

## Хранение и развёртывание

Добавлена миграция `20261021073551_AddCatalogProductAnalogyConfigurations`. Она создаёт таблицу `catalog_product_analogy_configurations`, уникальную нумерацию внутри области и ограничение на одну активную версию области. Миграция создана в проекте, но к рабочей базе данных не применялась.

## Оценка и выпуск

Черновик оценивается на снимке существующих товаров выбранной области, у которых есть сохранённые характеристики. Для каждого контрольного значения сравниваются предложение действующей конфигурации и предложение черновика. Отчёт сохраняет строки сравнения, снимок кандидатов, хэши обеих конфигураций, улучшения, регрессии и причины запрета выпуска.

Выпуск разрешён только при наличии не менее трёх контрольных товаров и значений, хотя бы одного подтверждённого улучшения, отсутствии регрессий и отсутствия роста неправильных предложений. Перед включением сервер повторно проверяет версию строки, хэш черновика, действующую конфигурацию и снимок товаров. Переключение активной версии и перевод предыдущей в `Superseded` выполняются одной транзакцией.

Для безопасного возврата старая версия напрямую не включается. Из неё создаётся новый черновик, который должен получить свежий отчёт.

## AutoFill

Режим `AutoFill` применяется только из действующей версии. Он заполняет отсутствующее значение, не заменяет данные Excel, ручные значения или результат строгого распознавания и сохраняет происхождение: конфигурацию, её номер, поддержку и товары-аналоги.

## Дополнительная миграция
