## [0.1.0-beta.1] - 2026-07-30

Первая тестовая beta-версия ElectronicCRM.

### Added

- регистрация пользователей;
- JWT-аутентификация;
- профиль пользователя;
- каталог товаров;
- управление типами товаров;
- управление характеристиками;
- привязка характеристик к типам товаров;
- импорт каталога из XLSX;
- автоматическое определение структуры импортируемого файла;
- ручное сопоставление колонок;
- обработка импортов, требующих исправления;
- очередь проверки импортов;
- XLSX-отчёт с ошибками;
- словарь нормализации каталога;
- начальное заполнение справочных данных;
- очистка просроченных незавершённых импортов;
- liveness и readiness health checks;
- PostgreSQL migrations при запуске;
- OpenAPI и Scalar для development-окружения;
- production Dockerfile для backend;
- standalone Dockerfile для frontend;
- корневой Docker Compose для PostgreSQL, API и Web;
- постоянный volume для PostgreSQL;
- постоянный volume для ASP.NET Core Data Protection;
- запуск контейнеров приложения без root-прав;
- конфигурация через `.env`.

### Changed

- frontend приведён к feature-oriented структуре;
- обработка Problem Details централизована;
- версии NuGet-пакетов управляются централизованно;
- Next.js обновлён до `16.2.12`;
- PostgreSQL закреплён на major-версии `18`.

### Security

- JWT-секрет вынесен из исходного кода;
- PostgreSQL-пароль вынесен в `.env`;
- локальные env-файлы исключены из Git;
- backend и frontend запускаются от непривилегированных пользователей;
- CORS origins задаются конфигурацией;
- production OpenAPI UI отключён.

### Known limitations

- версия не предназначена для публичного production-развёртывания;
- HTTPS и reverse proxy отсутствуют;
- автоматизированные тесты импорта пока не добавлены;
- CI/CD отсутствует;
- резервное копирование базы выполняется вручную;
- npm audit может сообщать об upstream-зависимости Sharp, используемой Next.js.
